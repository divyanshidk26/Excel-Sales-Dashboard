# Executive Summary & Profitability Dashboard

A comprehensive sales and profitability dashboard built entirely in Microsoft Excel.

## Overview
This project features an *Executive Summary & Profitability Dashboard* designed to track, analyze, and visualize core business performance metrics. It utilizes advanced Excel features including pivot tables, dynamic charts, and interactive slicers.

## Key Performance Indicators (KPIs)
The dashboard tracks the following high-level financial and operational metrics:
* *Total Revenue*: $6,45,223
* *Total Profit*: $2,96,384
* *Gross Profit Margin*: 45.94%
* *Total Units Sold*: 6,698
* *Total Orders*: 2,707
* *Cost of Goods Sold (COGS)*: $3,48,839

## Visualizations & Charts
The dashboard includes multiple interactive visual components to analyze sales trends:
* *Revenue and Profit Trend*: A line chart tracking monthly performance from January to December.
* *Top 5 Countries by Revenue*: A horizontal bar chart highlighting top-performing countries including the United Kingdom, Spain, Italy, Germany, and France.
* *Region-wise Comparison*: A donut chart breaking down regional performance across Central Europe, Northern Europe, Southern Europe, and Western Europe.
* *Country-wise Map Chart*: A geographic map visualization displaying revenue distribution across European countries.
* *Revenue Sales by Channel*: A distribution chart analyzing sales across Corporate, Online Store, Marketplace, and Retail Partners channels.

## Interactive Slicers & Filters
Users can dynamically filter and slice data using built-in controls:
* *Product Category Filter*: Filter data by Camping, Cycling, Fitness, Hiking, and Travel.
* *Country Filter*: Filter data dynamically by specific countries such as Austria, Belgium, Czechia, Denmark, Finland, France, Germany, and Ireland.

## Workbook Structure
The Excel workbook is organized into distinct tabs:
* *Dashboard*: The main interactive visualization interface.
* *Pivot Tables*: Underlying pivot tables driving the analytics.
* *Data*: Raw source data repository
